# ADR template

Copy this file to `NNNN-slug.md` and fill in every section.

```
# NNNN. Title

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded by NNNN

## Context

Why this decision is needed now; verified facts and their sources.

## Decision

What we will do, stated concretely enough to verify compliance.

## Consequences

What becomes easier, what becomes harder, what this forbids.

## Compliance

How an agent or reviewer can check that code matches this decision.
```
